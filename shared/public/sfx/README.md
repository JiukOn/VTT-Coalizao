# SFX Assets

Place `.mp3` sound effect files here. Expected files:

- `dice_roll.mp3` — Dice rolling sound
- `combat_hit.mp3` — Successful attack hit
- `combat_miss.mp3` — Missed attack / dodge
- `turn_alert.mp3` — Turn change notification
- `notification.mp3` — General notification

Keep files under 50KB each for fast loading.
Use royalty-free sounds (e.g., from freesound.org).
